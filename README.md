## Entropic HDR 1.0.0

An OBS plugin that acts like the optimal filter for a camera: it measures entropy across the frame and respends the picture's color, brightness and contrast where the information is. See [paymenottowork.com/instruments/entropic-hdr](https://paymenottowork.com/instruments/entropic-hdr/).
